# Python for Beginners: Complete Course Notes

This repository contains a comprehensive guide and code implementation for beginners starting their journey with Python. It covers everything from basic syntax to Object-Oriented Programming (OOP).

## 📚 Course Syllabus

### 1. Introduction to Python
- What is Python? (Interpreted, High-level, General-purpose language)
- Setting up the environment (Python installation, IDEs like VS Code/PyCharm)
- Your first program: `print("Hello World")`

### 2. Variables and Data Types
- **Variables:** Containers for storing data values.
- **Basic Data Types:**
    - `int`: Integers (e.g., 10, -5)
    - `float`: Floating point numbers (e.g., 10.5, 3.14)
    - `str`: Strings (e.g., "Hello")
    - `bool`: Booleans (`True` or `False`)
- **Type Casting:** Converting one type to another (e.g., `int("10")`).

### 3. Operators
- **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%`, `**` (exponent), `//` (floor division)
- **Comparison Operators:** `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Logical Operators:** `and`, `or`, `not`
- **Assignment Operators:** `=`, `+=`, `-=`, etc.

### 4. Control Flow
- **Conditional Statements:** `if`, `elif`, `else`
- **Loops:**
    - `for` loop: Iterating over a sequence (list, range, string).
    - `while` loop: Executing as long as a condition is true.
- **Loop Control:** `break` (exit loop), `continue` (skip current iteration).

### 5. Data Structures
- **Lists:** Ordered, mutable, allows duplicates. `[1, 2, 3]`
- **Tuples:** Ordered, immutable, allows duplicates. `(1, 2, 3)`
- **Dictionaries:** Unordered, mutable, key-value pairs. `{"name": "Alice", "age": 25}`
- **Sets:** Unordered, mutable, unique elements. `{1, 2, 3}`

### 6. Functions and Modules
- **Defining Functions:** Using the `def` keyword.
- **Arguments & Return Values:** Passing data to functions and getting results back.
- **Scope:** Global vs Local variables.
- **Modules:** Using `import` to use code from other files or libraries (e.g., `math`, `random`).

### 7. File Handling & Exception Handling
- **File I/O:** Opening, reading, writing, and closing files (`open()`, `with` statement).
- **Error Handling:** Using `try`, `except`, `finally` to prevent program crashes.

### 8. Object-Oriented Programming (OOP)
- **Classes and Objects:** Blueprints and instances.
- **Constructors:** The `__init__` method.
- **Attributes and Methods:** Data and functions within a class.
- **Inheritance:** Creating a new class from an existing one.
