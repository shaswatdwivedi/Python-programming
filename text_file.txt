🚀 PYTHON QUICK-START GUIDE: IMPORTANT NOTES 🚀
================================================

1. BASICS & DATA TYPES
----------------------
- Variables: Just containers. No need to declare types (Dynamic Typing).
- Key Types:
    * int (10), float (10.5), str ("Hello"), bool (True/False).
- Type Casting: Use int(), float(), str() to convert between types.

2. CONTROL FLOW (The "Brain" of your code)
-------------------------------------------
- If/Elif/Else: Used for decision making.
- For Loop: Best for iterating over a fixed sequence (lists, ranges).
- While Loop: Best for repeating as long as a condition is True.
- Break vs Continue:
    * 'break' kills the loop entirely.
    * 'continue' skips the current step and goes to the next one.

3. DATA STRUCTURES (Where to store data)
-----------------------------------------
- List [ ]: Ordered, Mutable (Can change), allows duplicates. (Most used!)
- Tuple ( ): Ordered, Immutable (Cannot change). Fast and safe.
- Dictionary {key: value}: Unordered, fast lookup using a unique key.
- Set { }: Unordered, Unique elements only. (Great for removing duplicates).

4. FUNCTIONS & MODULARITY
-------------------------
- def keyword: Used to create reusable blocks of code.
- return: Sends a value back to the caller.
- Lambda: One-line "anonymous" functions for quick tasks.
- Modules: Use 'import' to bring in power from other files (like 'math' or 'random').

5. ERROR & FILE HANDLING
------------------------
- Try/Except: Wrap risky code in 'try' to prevent the whole program from crashing.
- 'with open(...)': Always use the 'with' keyword when opening files—it closes the file automatically, even if an error occurs.

6. OBJECT-ORIENTED PROGRAMMING (OOP)
------------------------------------
- Class: A blueprint (e.g., a "Car" blueprint).
- Object: An instance of the blueprint (e.g., "My Red Tesla").
- __init__: The constructor method that sets up the object's initial data.
- Inheritance: Creating a child class from a parent (e.g., Dog inherits from Animal).
- Encapsulation: Using double underscores (__) to make data private.

7. PRO TIPS FOR SUCCESS
-----------------------
- Indentation: Python RELIES on indentation (4 spaces). Wrong indentation = Error.
- List Comprehension: Use [x for x in list] to replace simple for-loops.
- F-Strings: Use f"Hello {name}" for the easiest and fastest way to format strings.
- PEP 8: The official style guide for Python. Follow it to write professional code.

================================================
HAPPY CODING! 🐍
